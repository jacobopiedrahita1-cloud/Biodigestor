# Biodigestor: de residuos a energía

Página web interactiva para la feria de ciencias sobre la producción de metano a partir de
residuos de frutas y verduras en un biodigestor escolar durante 40 días.

Institución Educativa Aureliano Flórez Cardona · Grado 11-A · Tecnología e Informática · Anserma, Caldas · 2026

Autores: Juan Pablo Piedrahita Hurtado, Juan Miguel Piedrahita Hurtado y Jerónimo Muñoz Moreno.

## Uso

Abre `index.html` con doble clic. Es un único archivo (HTML, CSS y JavaScript) y funciona sin internet.

- Flechas izquierda/derecha: cambiar de escena
- `E`: modo exposición · `F`: pantalla completa · `M`: sonido

## Desarrollo

El código fuente está en `src/` (`style.css`, `body.html`, `app.js`). Para regenerar `index.html`:

```
python3 build.py
```
